Mobile Deb

在 Android 上运行 Debian。

Mobile Deb 是一个面向 Android 的开源 Debian 运行环境，无需 Root，即可在手机上使用 Debian ARM64 用户空间。

功能

- 🐧 运行 Debian ARM64
- 💻 提供内置终端
- 📂 与 Android 共享文件
- 🔧 基于 PRoot 运行，无需 Root
- 📦 支持安装和使用 Debian 软件包
- 🔓 免费、开源

用途

Mobile Deb 可以让你的 Android 手机拥有一个便携的 Debian 环境。

你可以用它：

- 使用 Linux 命令行工具
- 安装 Debian 软件包
- 编写和运行程序
- 管理文件
- 搭建自己的移动开发环境
